Welcome to SKG Chess

Hello! I'm Haris, and I'm excited to welcome you to SKG Chess. This platform is designed to help you play chess online with friends. Hope you enjoy the game!

Features

SKG Chess offers a range of features to enhance your chess experience:

  • Play against friends
  • Customize your board and pieces while in game
  • Keep track of your match history

SKG Chess Development Story

The Idea

SKG Chess (named after my hometown Thessaloniki) is an ongoing project I developed out of my passion for chess and software development.

The Inspiration

Having spent many hours on renowned chess platforms, I chose to build a chess application to explore how chess logic and rules are applied in code.

The Technology Choice

I chose Java programming language as its object-oriented nature aligns well with chess thinking.

The Evolution

My passion for chess and growing expertise in backend development at that time inspired me to evolve it into a full-stack web application using Spring Boot.

The Features

The project encompasses real-time communication, user authentication, database persistence, security, and other enterprise-grade features, allowing me to expand my technical expertise while building something meaningful.

The Future

Today's version represents the initial implementation, and I aim to continuously improve it to enhance my backend development skills, with plans to make it useful for the local chess community in Thessaloniki.

Tech Stack

Backend Core

Pure Java (JDK 17) for the chess game logic, ensuring robust and efficient move validation and game state management

Web Framework

Spring Boot 3.2.3 providing RESTful API endpoints, WebSocket support for real-time gameplay, Spring Security for authentication, and JPA for database persistence

Frontend

Thymeleaf templating engine with HTML/CSS/JavaScript for a responsive and interactive user interface

Database

SQLite for local development and PostgreSQL for production, with JPA for object-relational mapping

Additional Technologies

Lombok for reducing boilerplate code, Gson for JSON processing, Guava for utility functions, and JUnit 5 for comprehensive testing

Project Structure

Modular architecture with separate packages for core logic, security, data persistence, controllers, services, DTOs, exception handling, and configuration
