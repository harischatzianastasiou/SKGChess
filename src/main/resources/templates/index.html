Features

Tech Stack

×
×
Frontend
Thymeleaf: Server-side rendering and dynamic templates.
HTML/CSS/JavaScript: Responsive UI, interactive chessboard, real-time updates.
Backend
Java (JDK 17): Core chess logic, move validation, game state management.
Spring Boot 3.2.3: REST API, WebSocket, Security, JPA.
Database
PostgreSQL: For game data, user management and messages.
Spring Data JPA: Object-relational mapping and data access layer.
Project Structure
Monolithic architecture with separate packages for core logic, security, data persistence, controllers, services, DTOs, exception handling, and configuration.
Additional Technologies
Lombok: Reduces Java boilerplate code.
JUnit 5: Comprehensive testing framework.
