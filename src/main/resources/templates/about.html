Welcome to SKG Chess

Hello there! I'm Haris and I'm excited to welcome you to my chess platform. As a software developer with a love for the game of chess, I created SKG Chess as a way to combine my passion for software development with my interest in the game.

Below you can find the story of how this project came to life

The Idea

The idea was to create a chess engine that would be able to play against a human opponent. I was mainly interested in how the chess logic and rules are applied in code and this began my journey into the world of chess programming.

The first steps

I chose Java programming language to develop the project as its object-oriented nature aligns well with chess thinking. After a few months exploring and honing the game logic, I started adding more and more features to make the experience more engaging.

The evolution

My passion for chess and growing experience in backend development at that time inspired me to evolve it into what you see today, a full-stack web application using Spring Boot framework! The name SKG Chess was inspired by my hometown, Thessaloniki.

The Features

The project encompasses real-time communication with WebSockets (real-time gameplay and game chat), customizable game themes, match history, and rating system.

The Future

Today's version represents the initial implementation. My goal is to continuously improve it to enhance my backend development skills, with plans to make it useful for the local chess community in Thessaloniki.

Explore tech stack

Tech Stack

Backend Core

Pure Java (JDK 17) for the chess game logic, ensuring robust and efficient move validation and game state management

Web Framework

Spring Boot 3.2.3 providing RESTful API endpoints, WebSocket support for real-time gameplay, Spring Security for authentication, and JPA for database persistence

Frontend

Thymeleaf templating engine with HTML/CSS/JavaScript for a responsive and interactive user interface

Database

SQLite for local development and PostgreSQL for production, with JPA for object-relational mapping

Additional Technologies

Lombok for reducing boilerplate code, Gson for JSON processing, Guava for utility functions, and JUnit 5 for comprehensive testing

Project Structure

Modular architecture with separate packages for core logic, security, data persistence, controllers, services, DTOs, exception handling, and configuration
