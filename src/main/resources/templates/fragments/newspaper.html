ICT and Computing!

by Annie Mator

In your lessons over the next few weeks, you will be learning computer science. For instance, you will learn how to code, program computers, understand how computers work, and build computers. You will also develop your ability to use programming languages (like this!) to create your very own web pages (right here!)

You will learn programming languages HTML, CSS and JS. (Just for reference, this article has been written using HTML and CSS programming languages!)! Even more exciting, you will be doing all of this with Codepen (that's this interactive programming environment)! During your lessons, you can experiment and develop your programming skills whilst also seeing your programming skills develop in real-time, online in your web browser!
